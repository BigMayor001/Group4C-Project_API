Getting Started
Prerequisites
Node.js v18 or higher
npm
Postman (optional, for testing)

Installation:

Clone the repository:
git clone : https://github.com/BigMayor001/Group4C-Project_API

Move into the project folder:
cd Group4C-Project_API

Install dependencies:
npm install

(Optional) Create a .env file in the project root to change the port. If you skip this, the server uses port 3001:
PORT=3001

Start the server:
node App.js
The API runs on http://localhost:3001 (or the port in your .env).

Note Object
Field	 Type	  Description
id	     number	  Unique ID, generated by the server
title	 string	  Title of the note
content	 string	  Body text of the note

Example:

{
  "id": 1,
  "title": "Shopping list",
  "content": "Milk, Bread, Eggs Oat, Sardine"
}
